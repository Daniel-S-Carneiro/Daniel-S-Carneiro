## 🚀 Projetos em destaque

### 📚 [Onde Parei – Where I Left Off](https://github.com/Daniel-S-Carneiro/Onde-Parei)
Biblioteca pessoal de leitura para mangá, manhwa, manhua, webtoon e novel. O app guarda em que capítulo você parou e abre os seus próprios links num leitor embutido, com bloqueio de anúncios.
`Flutter` · `Dart` · `Windows` · `Linux` · `Android`

> Nasceu a partir do **[MangasApp](https://github.com/Daniel-S-Carneiro/MangasApp)**, meu projeto anterior, hoje descontinuado e arquivado.

### 🎮 [RealTime Screen Translator](https://github.com/Daniel-S-Carneiro/RealTime-Screen-Translator)
Tradutor de tela em tempo real para Windows, feito para jogos. Você posiciona a janela sobre o texto e com um clique ele faz o OCR e traduz para mais de 80 idiomas. Funciona com Google, DeepL, Azure ou em modo totalmente offline.
`Python` · `EasyOCR` · `CUDA` · `Windows`
